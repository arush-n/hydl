# ADK documentation

This directory contains the user-facing reference notes for the ADK surface:
composite actions, contextual collection, hierarchical runtime, imitation, and
runtime wiring.

The implementation entry point is [`../api.py`](../api.py). Use
[`../capability/README.md`](../capability/README.md) for the public capability
vocabulary and [`HIERARCHICAL-RUNTIME.md`](HIERARCHICAL-RUNTIME.md) for hierarchical
collection. The public imitation interfaces are described by the Arena
training documentation; capture records and developer audit notes are not
part of the published surface.

For the broader project orientation, return to [`../../README.md`](../../README.md).
