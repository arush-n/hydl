# come_here — go to someone who calls (planned)

Walk to an entity and stop within reach of it: walk_to with the entity's pointer instead of a position. It needs no
new simulator mechanic, so it is the first skill after the walk_to and look_at release.

**Status (2026-10-19): planned, no code.** The plan is `TRAINING.md` (proposed, not approved): what it does, its
teacher, world, student, bars, stages and what it waits on. When it is built, this folder gets the files of
`../walk_to/`: `teacher.py`, `task.py`, `certify.sh`, `train.sh` and `evaluate.sh`. The index of every skill is
`../README.md`.
